
## How to Install and Run the Project

### Run in Jupyter Notebook
 ####  Create venv
    - macOS/Linux: python3 -m venv .venv && source .venv/bin/activate
    - Windows (PS): python -m venv .venv && .\.venv\Scripts\Activate.ps1 

 #### Install Dependencies
    - With file: pip install -r requirements.txt
    - Or uncomment the first code block and run: %pip install pandas scikit-learn matplotlib seaborn jupyter numpy scipy

#### Run notebooks
    - Open text_classification.ipynb -> Run All
    - Open text_clustering -> Run All
